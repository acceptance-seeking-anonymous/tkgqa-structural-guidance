JSON schema (all keys required, in this order):
- mentions: list of {"text": the entity mention copied from the question, "entity": its exact KG entity name}
- relation: exactly one KG relation name from the list below
- answer_role: subject | object
- qtype: equal | before_after | first_last | equal_multi | after_first | before_last
- answer_type: entity | time
- granularity: day | month | year
- time: the explicit time in the question as YYYY, YYYY-MM or YYYY-MM-DD, or null
- anchor: the exact KG entity name of the reference event's entity in "before/after <entity>" questions, or null
- order: before | after | first | last | null

Definitions:
- answer_role: object if the main entity of the question is the subject (actor) of the relation and the answer fills the object slot; subject if the main entity is the object (target) and the answer is the actor. For time answers: object if the first-mentioned entity is the actor towards the second, else subject.
- qtype equal: a single event at the given time, or (time answer) when a single event happened.
- qtype before_after: events before or after the given time (order = before | after).
- qtype first_last: the first or last such event, or its time (order = first | last).
- qtype equal_multi: the first or last event within the given time (order = first | last), or an event in the same day, month or year as the anchor's event.
- qtype after_first: the first event after the event involving the anchor entity (order = after).
- qtype before_last: the last event before the event involving the anchor entity (order = before).
- granularity: for time answers the granularity asked for ("when" = day, "in which month" = month, "in which year" = year); for entity answers the granularity of the explicit time, day if there is none.

KG entity names: countries, persons and organisations by their full name (e.g. "South Korea", "Barack Obama", "East African Community"); sectors, roles and groups of a country as "Sector (Country)" with a singular sector (e.g. "Citizen (Brazil)", "Police (Kenya)", "Head of Government (Greece)", "Ministry (Sudan)"); groups of an organisation as "Role (Organisation)" (e.g. "Insurgency (Al-Shabaab)").
